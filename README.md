# Northline Physiotherapy — Demo Build

**Bukan proyek klien nyata.** Landing page contoh yang dibangun sebagai
aset Project Catalog Upwork oleh Glodigs — Global Digital Growth Studio.
Nama klinik, alamat, harga, dan kontak bersifat fiktif.

**Live:** https://inggrisgarem-dotcom.github.io/northline-demo/

## Spesifikasi teknis
- HTML/CSS/JS murni — tanpa framework, tanpa dependensi eksternal
- Satu berkas, 23 KB
- Font: Fraunces (display) + Inter (body)
- Palet: petrol #1B4842, saffron #D9922B, paper #FBFAF6
- Navigasi mobile: CSS checkbox pattern, tidak bergantung JavaScript
- Diagram range-of-motion: SVG dengan sweep 42°→158°, posisi akhir
  tertulis di markup sehingga tampilan tetap benar bila JS gagal
- Menghormati `prefers-reduced-motion`
- 6 breakpoint + tipografi fluid `clamp()`
